## 결론 (숫자만)

- 발화(57세션 중): V0 39, V1 55, V2 57, V3 36. V1 − V0와 V2 − V0는 태스크 19개 중 늘어남 9, 줄어듦 0(부호 검정 p 0.004). V3 − V0는 늘어남 4, 줄어듦 5(p 1.000).
- V3의 발화 36 중 19는 (b) MCP 직접(ToolSearch 먼저)이었다. V0–V2의 (b)는 0이다.
- 첫 도구가 탐색(Read·Grep·Bash)인 세션: V0 18, V1 2, V2 0, V3 20.
- 로드한 세션의 적중(관련 1개 이상): V0 0.81, V1 0.78, V2 0.76, V3 0.76. 관련 없음 태스크 2개에서 search한 세션 중 1개 이상 로드: V0 3/3, V1 5/6, V2 6/6, V3 2/2.
- 세션 비용 평균: V0 $0.396, V1 $0.455, V2 $0.533, V3 $0.384.
- 4번째 쿼리가 요청 원문과 글자 그대로 같은 세션: 요청 400자 미만 100/120, 800자 이상 0/40.
- 바뀌지 않은 10태스크의 발화: 4단계 E1 14/30, 5단계 V0 19/30.

## 알려진 한계

- 같은 모델, 반복 3회. 변형당 57세션이라 두 비율 차의 95% 오차는 약 ±0.18이다.
- E1(깨끗한 환경)만 돌렸다. 사용자 전역 설정이 있는 환경(4단계 E2)에서는 재지 않았다.
- oracle과 세션 모델이 같다(Opus 5.5). 3단계 GPT 교차 라벨의 관련 여부 kappa는 0.482였다(`stage3/report-cross-label.md`).
- 다시 쓴 9개 중 5개는 같은 텍스트로 oracle을 두 번 돌렸는데, 4개의 관련 세트가 달랐다(`DESIGN.md`).
- 작업 결과물은 채점하지 않았다. 발화 뒤의 작업 품질이 나아졌는지는 이 보고서로 알 수 없다.
- 결과는 공개 이후 측정이다. numbers.md에서는 레포 세션의 "after the post" 규칙(§7 합계 밖 별도 행)으로 들어간다.
